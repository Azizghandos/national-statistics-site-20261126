NusantaraStats — an original national statistics site for Indonesia: population, economy, employment, education & health, covering all 38 provinces, with real BPS (Statistics Indonesia) figures cited with source and year, hand-drawn SVG charts, and plain static files — no network calls, works on desktop and phone.

## Run it

```sh
node serve.ts
```

(then open http://localhost:8080 — the hand-in program is main.ts, run with `MAKEFUN_OUTPUT_DIR=out node main.ts`)
